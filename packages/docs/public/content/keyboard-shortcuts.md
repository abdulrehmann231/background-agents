# Keyboard shortcuts

Shortcuts for moving around the app without reaching for the mouse.

| Shortcut | Action |
|----------|--------|
| `⌘P` / `Ctrl+P` | Search chats, repos, and branches |
| `⌘K` / `Ctrl+K` | Command palette |
| `⌘B` / `Ctrl+B` | Toggle sidebar |
| `⌘J` / `Ctrl+J` | Toggle terminal |
| `⌘S` / `Ctrl+S` | Skills |
| `⌘O` / `Ctrl+O` | New chat |
| `⌘⇧O` / `Ctrl+Shift+O` | Branch chat |
| `⌥↑` / `⌥↓` or `Alt+↑` / `Alt+↓` | Switch chats |
| `⌥Enter` / `Alt+Enter` or `⇧Enter` / `Shift+Enter` | Branch and send to a new chat |

> [!TIP]
> The command palette (`⌘K`) always works, whether or not its button is shown in the header — toggle the button itself in **Settings → Appearance**.

## Git actions

Type `/` in the prompt for merge, rebase, squash, and opening a PR.
